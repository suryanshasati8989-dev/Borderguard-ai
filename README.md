# BorderGuard AI

A Defense-Grade Command, Control, Communications, Computer, Intelligence, Surveillance and Reconnaissance (C4ISR) application for tactical border security.

## Features
- Real-time video stream analytics (YOLOv8 & COCO-SSD)
- Mobile roaming camera support via QR code ingestion
- Customizable Virtual Borders (Line Crossing & Restricted Zones)
- Live Alerting & Threat Prioritization (Human, Vehicle, Animal)
- Tactical HUD interface

## Setup
Run the `DEPLOY.bat` file on Windows to automatically build the frontend, check the environment variables, and start the production WSGI server.
